# The Last Garden: artwork provenance

Prepared 15 October 2026. All source reads came from the AITokenGarden source project. That project was left unchanged. This game keeps its own adapted copy and does not require access to the original desktop folder at runtime.

## Source-derived robots

The playable characters are adapted from the actual procedural React/SVG geometry in `AITokenGarden/video/src/robots`, rather than cut out of the opaque PNG contact sheets in `video/out/robots`. The source character sheets were used as references. The body shells, face screens, limbs, gardening accessories, signatures, expressions, and deterministic pose functions are retained.

| Source in AITokenGarden | Game destination | Adaptation |
|---|---|---|
| `video/src/robots/Robot.tsx` | `src/scene/robots/Robot.tsx` | Browser-supplied clock replaces Remotion; maker badges and maker nameplates removed. |
| `video/src/robots/parts.tsx` | `src/scene/robots/parts.tsx` | Original geometry; maker-logo drawing and generated-logo dependency removed. |
| `video/src/robots/signatures.tsx` | `src/scene/robots/signatures.tsx` | Original source motifs and deterministic motion. |
| `video/src/robots/motion.ts` | `src/scene/robots/motion.ts` | Original pose rig with a local 30 FPS clock constant. |
| `video/src/robots/expressions.ts` | `src/scene/robots/expressions.ts` | Original face vocabulary. |
| `video/src/robots/cast.ts` | `src/scene/robots/cast.ts` | Geometry types retained; cast rewritten as fictional campaign appearances. |
| `video/src/lib/iso.ts` | `src/scene/lib/iso.ts` | Only `mix` and `shade` color helpers extracted. |

The original SHA-256 hashes and byte sizes are recorded in `public/assets/robot-source-manifest.json`. The source checkout revision was not read; the content hashes identify the exact inspected files. No Remotion runtime, voice-envelope data, source database package, official maker logos, remote images, or external font request ships with this scene.

The palette follows the source garden: forest greens, warm cream, lime accents, pastel robot shells, inset dark face screens, wooden garden props, and modest soft light. `src/scene/fonts.ts` supplies system font fallbacks instead of importing Remotion or Next.js font tooling.

## Environment and animation

`WorldScene.tsx` and `world.css` contain newly authored SVG/CSS environment composition created for this game by Codex: raised beds, original workbench, signs, solar arrays, campus buildings, city towers, river, bridge, roads, trees, flowers, and orbital station. These were composed to match the user's source artwork. The central conservatory is an Opus-authored SVG, described below. No stock images were used.

The five camera scales—Workbench, Garden, Campus, Region, Planet—move through one connected coordinate system. Buildings respond to chapter progression, flowers and growth to quality/welfare, fences to agency, and loss of tree diversity and path color to distortion/dependence. Future buildings are faint silhouettes before their chapters. The original garden stays at the same world coordinates throughout.

The planetary view is a stylized world diorama, not a geographic model of Earth. Animated daylight is decorative, not the economic clock. The robot presentation clock is capped at approximately 15 visual updates per second. There are at most seven full-body robots and twelve fireflies, regardless of producer count. Animation stops with the game pause, local art pause, reduced-motion prop, hidden document, or offscreen scene. CSS also respects the operating system's reduced-motion media query. All SVG IDs are scoped per component instance.

## Opus 5.5 conservatory

`public/assets/opus/conservatory.svg` is the complete, unchanged SVG building generated by Claude Opus 5.5 through the installed Claude Code CLI with `--effort max` and the matching effort environment override. Model identity was observed in initialization and stream metadata. Max reasoning was explicitly requested.

The artifact is 5,589 bytes, viewBox `0 0 240 200`, SHA-256 `2b906b0e8ac84f539648a0314838df23338df51ffea9687f879938bac9a04d83`. The raw generation transcripts remain in the local development archive. A complete SVG was extracted from streamed output; four complete copies were identical. The CLI did **not** finish cleanly or return final result/usage metadata: it was stopped after the artwork was complete and its output continued repeating inert tool-call syntax. That text was not executed. The SVG contains no executable content.

The conservatory is a visible landmark in the original garden at world anchor `(1120, 945)`, and remains in place while the camera moves through campus and planet scales. It is loaded as an SVG `image` using Vite's base URL so internal IDs remain isolated from the surrounding inline world. Its content is not edited, recolored, or represented as the entire game's authorship. The source-derived robot adaptation and other world composition remain Codex work.

## Reuse evidence

The user expressly requested their AITokenGarden graphics for this game. `AITokenGarden/public/garden-robots/SOURCES.md` identifies the same source renderer, cast, and static export recipe, and distinguishes illustrative activity from claims about named models. No general artwork redistribution license was found in the inspected source root. This document records the user's authorized project reuse; it does not invent an open-source or public-domain license for the source art.

Official logos were omitted, so the source logo usage documentation is not relied on as permission to associate a real maker with a fictional catastrophe. No audio is covered by this document; see `AUDIO_PROVENANCE.md` for audio provenance.

## Integration and inspection

```tsx
import { WorldScene } from './scene/WorldScene';
import { CharacterPortrait } from './scene/CharacterPortrait';
```

`WorldScene` receives `chapter`, `producerCount`, `quality`, `distortion`, `agency`, `welfare`, `dependence`, `paused`, `reducedMotion`, `onTend`, and optional `selectedCharacter`. All five metric props use 0–100 values. The component owns presentation-only camera state and calls `onTend` for its keyboard-accessible button and robot hotspot. It has no economy state or storage side effects.

`src/scene/ArtPreview.html` and `ArtPreview.tsx` provide a development-only inspection page, reachable through Vite at `/src/scene/ArtPreview.html`. They are not application entry points or copied public assets. It has chapter and strain controls for checking the visual consequences without changing a campaign save.

Verification completed: isolated strict TypeScript check passed for `WorldScene` and `CharacterPortrait`; the source-derived garden rendered in the in-app browser. A worker overlap found during visual inspection was corrected. Full application/mobile checks are handled by the parent build. The temporary art preview server and its hidden tab were closed after inspection.
